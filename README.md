# 🎄 Nossas Memórias de Natal ❤️

Um site interativo e romântico feito com HTML, CSS e JavaScript, criado para reviver memórias especiais e desbloquear uma surpresa final de Natal.

## ✨ Recursos

- 📖 **Linha do tempo interativa:** Histórias e lembranças de momentos marcantes.
- 🖼️ **Galeria de fotos:** Imagens integradas e suporte para adicionar fotos pelo rolo da câmera.
- 🧩 **Minigame de memórias:** Desbloqueio progressivo através de símbolos interativos.
- 🔒 **Presente final protegido por senha:** Validação segura com criptografia SHA-256.
- 📱 **PWA & Mobile-First:** Responsivo para celular, compatível com "Adicionar à Tela de Início".
- ❄️ **Efeito de neve:** Animações fluidas em CSS.

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/nossas-memorias-de-natal.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador ou use a extensão **Live Server** no VS Code.

## 🌐 Publicação no GitHub Pages

Para publicar este site e acessá-lo pelo celular:
1. No repositório no GitHub, vá em **Settings** > **Pages**.
2. Em **Branch**, selecione `main` e a pasta `/ (root)`.
3. Clique em **Save**.
4. O link gerado (`https://SEU_USUARIO.github.io/nossas-memorias-de-natal/`) poderá ser aberto em qualquer smartphone!
